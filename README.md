# Chorus Skills Marketplace

Official skills and commands collection for [Chorus](https://github.com/music-soul1-1/Chorus) - AI-powered Claude Code workflows.

## Available Skills

### Workflows
- **APEX** (`/apex`) - Systematic implementation with Analyze-Plan-Execute-eXamine methodology
- **Brainstorm** (`/brainstorm`) - Deep iterative research with parallel agents
- **Debug** (`/debug`) - Systematic error debugging workflow
- **Clean Code** (`/clean-code`) - Apply clean code principles to your codebase
- **CI Fixer** (`/ci-fixer`) - Auto-fix CI failures until green

### Git Utilities
- **Quick Commit** (`/commit`) - Fast commit with conventional messages
- **Create PR** (`/create-pr`) - Auto-generate PR with title and description
- **Fix PR Comments** (`/fix-pr-comments`) - Implement review feedback automatically
- **Smart Merge** (`/merge`) - Context-aware conflict resolution

### Code Quality
- **Code Review** (`/review-code`) - Expert review for security and quality
- **Fix Errors** (`/fix-errors`) - Fix ESLint/TypeScript errors in parallel
- **Refactor** (`/refactor`) - Codebase-wide refactoring with agents

### Productivity
- **Ultrathink** (`/ultrathink`) - Deep thinking mode for elegant solutions
- **Oneshot** (`/oneshot`) - Ultra-fast feature implementation
- **Fix Grammar** (`/fix-grammar`) - Fix grammar in files
- **Save Docs** (`/save-docs`) - Fetch and save library documentation

### Meta (Learn to Create)
- **Skill Creator** - Learn to create Claude Code skills
- **Workflow Creator** - Create multi-step workflow skills
- **Hooks Creator** - Create event-driven hooks
- **Prompt Creator** - Expert prompt engineering
- **Subagent Creator** - Create specialized agents

### AI Automation
- **Ralph Loop** - Autonomous AI coding while you sleep
- **Ralph Tasks** - Task queue for autonomous coding
- **SaaS Builder** - Complete SaaS ideation to implementation

## Installation

In Chorus, open the Plugin Marketplace and install any skill with one click.

## Manual Installation

```bash
# Clone to your Claude plugins directory
git clone https://github.com/YOUR_USERNAME/chorus-marketplace ~/.claude/plugins/chorus-marketplace
```
